Returns Policy

Demo Store accepts eligible product returns within 30 calendar days of delivery.

Return Window

Customers have 30 calendar days from the delivery date to request a return.

The return window begins when the package is delivered, not when the order is placed.

Return requests submitted after 30 calendar days are not eligible under the standard return policy.

Return Eligibility

Products must meet the following requirements:

The item must be unused and unworn.

The item must be in its original packaging.

All original accessories must be included.

Proof of purchase or an order number must be provided.

The return request must be submitted within 30 calendar days of delivery.

Non-Returnable Items

The following items cannot be returned under the standard return policy:

Gift cards

Digital downloads

Products marked Final Sale

Opened personal-care products

Damaged or Incorrect Items

Customers who receive damaged, defective, or incorrect items should contact customer support.

Customers should provide:

Their order number.

A description of the problem.

Photographs of the item, when available.

Customer support will review the issue and determine whether the return is approved.

Original packaging is not required for reporting damaged, defective, or incorrect items.

How to Return an Item

To initiate a return:

Contact customer support within 30 calendar days of delivery.

Provide the order number and reason for the return.

Wait for return authorization.

Follow the provided return-shipping instructions.

Keep the return tracking number or shipping receipt.

Customers should not ship products back before receiving return authorization.

Return Shipping Costs

Customers are responsible for return shipping costs when returning products because of:

A change of mind

An incorrect size selection

Personal preference

For approved returns involving damaged, defective, or incorrect products, Demo Store provides a prepaid return shipping label.

Return Inspection

Returned products are inspected within 2 business days after the returned package is received.

A refund is processed only after the return has been approved.

For refund processing times, refer to the Refunds Policy.
